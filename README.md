## THE가계 (영수증 인식 가계부)

OCR 기술을 활용해 영수증 사진 한 장으로 지출을 자동 기록하고 관리하는 Streamlit 기반 가계부 서비스입니다.

## 주요 기능

- 영수증 OCR 스캔: Google Vision API를 활용해 영수증 이미지에서 날짜, 금액, 품목을 자동으로 추출합니다.
- 지출 카테고리 시각화: 소비 패턴을 분석하여 차트로 한눈에 보여줍니다.
- 예산 설정 및 관리: 월별 예산을 설정하고, 현재 지출 현황에 따른 잔여 예산을 확인합니다.

## 기술 스택

- Web Framework: Streamlit
- OCR Engine: Google Cloud Vision
- Database: MySQL
- Language: Python 3.13

## 시작하기

1. Google Cloud Vision 세팅
2. 라이브러리 설치
3. 앱 실행
   - streamlit run App.py
